# CyberDog 第六赛段问题交接说明

> **给组长的简短说明：**
> 目前第六赛段代码已完成视觉找球和靠近球，但卡在贴球后的“推球/折返终点”阶段。已记录关键世界坐标，建议优先检查贴球后的状态机切换、步态前推能力，以及是否可以利用已测量的世界坐标辅助完成推球和回终点逻辑。

---

## 1. 当前代码状态

当前仓库版本已经可以实现以下功能：

* 开启摄像头及视觉扫描；
* 自动识别球的位置并朝球方向前进；
* 能够走到球旁边，并进入**贴球状态**。

**核心瓶颈：**
机器人可以找到球并靠近，但无法继续完成撞球动作，也无法在撞球后折返回终点位置（表现为停在球旁边不再继续推进）。

---

## 2. 当前主要 Bug 描述

机器人执行第六赛段逻辑时，可以正常完成：
`扫描视觉 → 找球 → 靠近球 → 停在球旁边`

但无法自动进入：
`撞球 / 推球 → 找终点 → 回到终点圈`

---

## 3. 怀疑方向与修复建议

### 3.1 步态文件问题 (Gait Files)

目前使用的是从 1-2 赛段复制的 `moonwalk` 步态。

* **怀疑点：** 步态速度不足或参数限制，导致贴球后无法产生足够的推进力。
* **建议：** 检查 `Gait_Params_moonwalk.toml` 等文件，确认是否支持持续负载前推。

### 3.2 状态机逻辑 (State Machine)

* **怀疑点：** 靠近球的阈值判断过早触发“完成”，或未正确跳转到 `PUSH_BALL` 状态。
* **建议：** 在贴球成功后加入一个**强制前推动作**（例如：调整朝向 → 持续前进 2-3 秒 → 再找终点）。

### 3.3 视觉与坐标辅助

* **怀疑点：** 终点识别逻辑（寻找无黄线区域）在贴球姿态下可能失效。
* **建议：** 既然已经测量了世界坐标，建议引入**坐标辅助导航**，在视觉丢失时通过坐标强行回位。

## 5. 运行环境与启动流程

### 环境准备

1. **WSL 宿主机：** 需安装 `x11-xserver-utils` 并启动 `xhost +` 以显示图形界面。
2. **Docker 容器：** 必须安装 `lcm` 和 `toml` 库。

### 启动步骤

1. **终端 1 (仿真环境):**
```bash
python3 src/cyberdog_simulator/cyberdog_gazebo/script/launchsim.py
python3 inject_sensors.py  # 注入传感器

```


2. **终端 2 (执行代码):**
```bash
source install/setup.bash
python3 run_stage6.py

```
